Вкладка таймера для [Caelestia Shell](https://github.com/caelestia-dots/shell) с родными цветами, типографикой, элементами управления и Material-фигурами.

## Возможности

Слева расположен обратный отсчёт, по центру — управление, справа — четыре именованных пресета. Волнистое кольцо заполняется по мере отсчёта, Material-фигура медленно вращается, а фоновые фигуры плавно перемещаются. Для волн используется тот же родной компонент, что и во вкладке Media. Движение останавливается на паузе и при скрытой вкладке; настройки анимации оболочки учитываются.

- Запуск, пауза, продолжение и сброс; длительность от одной секунды до 24 часов.
- Пресеты на 15, 30, 60 и 120 минут; названия и длительность можно изменить кнопкой настроек.
- Состояние и пресеты сохраняются между перезапусками оболочки. После сна запущенный таймер учитывает прошедшее время, а приостановленный остаётся на паузе.
- Системное уведомление и мягкий звук завершения с отдельными переключателями.
- Английские и русские подписи следуют языку оболочки; собственные названия пресетов сохраняются как введены.

## Установка

Нужны установленная Caelestia, Python 3 и Bash. Проверено с **Caelestia 2.5.0** и **Quickshell 0.3.1** на Hyprland. Уведомления отправляются через `notify-send`, звук воспроизводится через `pw-play`. Оба инструмента необязательны.

```sh
git clone https://github.com/necrasov-ilya/caelestia-timer.git
cd caelestia-timer
./install.sh --check
./install.sh --restart
```

Откройте Dashboard и выберите **Timer / Таймер** рядом с Media. Длительность можно ввести как `мм:сс`, `чч:мм:сс` или число минут, например `15`. Чтобы перезапустить Caelestia вручную, не указывайте `--restart`.

Установщик проверяет структуру панели до внесения изменений. Он добавляет модуль в пользовательскую конфигурацию и небольшие помеченные блоки интеграции в `shell.qml`, `modules/dashboard/Content.qml` и `modules/drawers/ContentWindow.qml`. Пока вкладка таймера открыта, поля длительности и пресетов могут получать ввод с клавиатуры.

Если оболочка установлена из пакета, остальные файлы остаются ссылками на системную установку, а три файла интеграции заменяются локальными копиями. Исходные файлы и ссылки сохраняются в резервной копии. Личные настройки сохраняются; файлы системного пакета не изменяются.

Для собственной копии оболочки или другого расположения:

```sh
./install.sh --target /path/to/user-owned/caelestia
# Явно указать оболочку, на которую будут ссылаться остальные файлы:
./install.sh --base /path/to/packaged/caelestia
```

`--restart` поддерживает только стандартную конфигурацию `caelestia`. Это дополнение панели с установщиком. У других версий оболочки структура интеграции может отличаться; неподдерживаемая структура отклоняется без изменений.

## Обновление и удаление

```sh
git pull
./install.sh --restart
# Удалить дополнение:
./uninstall.sh --restart
```

Обновление заменяет файлы дополнения, сохраняя состояние таймера, пресеты и посторонние изменения оболочки. Если файлы установленного дополнения изменены вручную, установщик обнаружит это; перед обновлением или удалением сохраните эти изменения отдельно.

При удалении восстанавливаются исходные файлы интеграции. Если вы внесли в них другие изменения, удаляются только помеченные блоки дополнения. Сохранённое состояние остаётся в `${XDG_STATE_HOME:-$HOME/.local/state}/caelestia-timer/state.json`.

Три файла интеграции являются локальными копиями. Перед обновлением самой Caelestia удалите дополнение, обновите оболочку и установите дополнение заново: так установщик проверит новую структуру и применит интеграцию к актуальным файлам. Если в этих файлах есть личные изменения, объедините их с обновлениями оболочки обычным способом.

## IPC

Таймером можно управлять через сочетание клавиш или другой инструмент:

```sh
qs -c caelestia ipc call timer status
qs -c caelestia ipc call timer duration 1800
qs -c caelestia ipc call timer start
qs -c caelestia ipc call timer pause
qs -c caelestia ipc call timer reset
qs -c caelestia ipc call timer preset 0 "Перерыв на чай" 900
qs -c caelestia ipc call timer sound false
qs -c caelestia ipc call timer notifications true
```

Длительность задаётся в секундах; индексы пресетов — от 0 до 3. Изменить длительность можно до запуска или после завершения. `start` также продолжает таймер с паузы. Уведомление и звук завершения срабатывают один раз, в том числе если отсчёт закончился, пока оболочка была остановлена.

## Разработка

```sh
node --test tests/timer.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
# Нужны графическая сессия и установленная Caelestia:
python3 tests/runtime_smoke.py --shell "$HOME/.config/quickshell/caelestia"
```

Проверка в Quickshell использует отдельное состояние и беззвучные замены команд уведомления и воспроизведения звука. Она не меняет таймер в запущенной оболочке. Переменная `CAELESTIA_TIMER_STATE_FILE` позволяет задать отдельный файл состояния для изолированного просмотра.
